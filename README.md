# choofauto - kit de démarrage

La bonne voiture. Au vrai prix. Vraiment disponible.

Ce dossier se place à la racine du dépôt avant la première session de Claude Code :

- `CLAUDE.md` : le contexte du projet et les règles de travail, lus par Claude Code à chaque session ;
- `docs/DECISIONS.md` : les décisions d'architecture ;
- `docs/PLAN-3-SEMAINES.md` : les tâches des trois premières semaines, avec la consigne à donner pour chacune ;
- `prisma/schema.prisma` : le schéma de base de données du pilote (validé avec Prisma 6.19) ;
- `prisma/seed.ts` : la Tunisie, les marques, les 30 modèles et les showrooms du Grand Tunis ;
- `docker-compose.yml` et `.env.example` : la base locale et les variables d'environnement.

Pour commencer : créer le dépôt, y copier ce dossier, ouvrir Claude Code à la racine et lui donner la consigne de la tâche 1.1.
